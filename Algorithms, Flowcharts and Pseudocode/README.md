# Khwezi Mining App Documentation

This folder contains the **algorithms, pseudocode and flowcharts** for the Khwezi Mining Health, Safety and Equipment Monitoring Application. It is written from the supplied project brief and the implemented Streamlit application.

## How to use on GitHub

Upload this whole folder into the same GitHub repository as the application. GitHub displays the Markdown files and Mermaid flowcharts automatically in the browser; no extra software is required.

## Documentation map

| Folder | Contents |
|---|---|
| [`algorithms/`](algorithms/ALGORITHMS.md) | Step-by-step logic for the main system functions |
| [`pseudocode/`](pseudocode/PSEUDOCODE.md) | Language-independent pseudocode matching the algorithms |
| [`flowcharts/`](flowcharts/FLOWCHARTS.md) | GitHub-rendered Mermaid flowcharts for the same functions |

## Functions covered

1. User login and role-based access control
2. Administrator account creation
3. Password update
4. Data upload and validation
5. Global search
6. Worker safety record and risk classification
7. Incident recording and filtering
8. Equipment condition monitoring
9. Maintenance priority monitoring
10. Risk assessment
11. Alert generation
12. Dashboard and role-based navigation

## Important note

The monitoring limits are educational prototype rules from the project brief. They are not manufacturer limits or operational mine safety limits.
